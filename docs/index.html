まずはここから

このアプリでできること

XIVcaは、アイテムのレシピツリーと必要素材を調べ、複数の製作予定をお気に入りとして保存・合算できるWebアプリです。ゲームへのログイン、ゲームクライアントとの連携、通信内容の取得は行いません。

対応している機能

  • アイテム名検索、装備条件検索、素材からの逆引き
  • レシピツリー、必要素材、クリスタル、交換素材の計算
  • 中間素材の購入・準備済み指定と製作方法の選択
  • 複数のお気に入りリストと製作条件の保存
  • 表示内容のテキスト・画像共有、シェアコード、ファイル入出力

データの取得元と利用上の前提

アイテム、レシピ、ショップ、採集などの通常データは、FINAL FANTASY XIV公式サイト「Lodestone」のエオルゼアデータベースを取得元としています。掲載内容は更新時点のデータであり、ゲーム内の最新状態と一致しない場合があります。

対応するブラウザーと端末

すべての画像と主要機能を利用するには、WebPとアプリが使用するWeb標準に対応した次のバージョン以降が必要です。

  • Google Chrome 93以降
  • Microsoft Edge 93以降
  • Mozilla Firefox 113以降
  • Safari 16.4以降
  • Brave 1.29以降

Windows、macOS、LinuxのPC、Androidのスマートフォン・タブレット、iPhone、iPadに対応します。共有、ファイル保存、ホーム画面・デスクトップへの追加方法はOSとブラウザーによって異なります。iPhone・iPadでホーム画面へ追加する場合はSafariを使用してください。安全性と互換性のため、利用可能な最新版への更新を推奨します。

基本的な使い方

アイテムを検索する

左パネルの検索欄へアイテム名の一部を入力し、候補から目的のアイテムを選びます。

レシピツリーを確認する

検索候補を選ぶと、完成品から中間素材までの製作順序をレシピツリーで確認できます。

必要素材と個数を確認する

必要に応じて完成品の個数を変更し、「素材リスト」を選ぶと、必要数が種類ごとに合算されます。

素材からレシピを逆引きする

レシピを持たない素材を検索して選ぶと、その素材を直接使用するアイテムを中央パネルで確認できます。

画面の移動方法

PC・タブレットでは、検索・お気に入りを操作する左パネル、検索結果や素材の使用先を表示する中央パネル、レシピツリーや素材リストを表示する右パネルを同時に確認できます。

スマートフォンでは、画面を左右へスワイプして各パネルへ移動します。

タイトルロゴから初期画面に戻る

画面上部のタイトルロゴを選ぶと、表示中の検索・計算を終了して初期画面に戻ります。保存済みのお気に入りは消えません。

装備を条件検索する

検索条件を指定する

検索欄の「▼」から装備検索を開き、ジョブ、装備レベル、アイテムレベルなどの条件を指定します。

部位ごとの装備を選ぶ

検索すると条件に合う装備が部位ごとに表示されます。お気に入りへ登録したい装備を選びます。

検索結果をお気に入りへ登録する

「検索結果をお気に入り登録」を選び、リスト名を指定して保存します。

製作方法と素材を調整する

製作方法を選ぶ

複数のレシピがあるアイテムでは、使用する製作ジョブと材料を選択できます。選択内容は素材計算とお気に入りへ反映されます。

中間素材を購入して用意する

素材リストで中間素材の「🛒」を選び、「この中間素材は購入💰して用意する」にチェックを入れると、その中間素材を製作せず購入して用意するものとして計算します。

中間素材を準備済みにする

素材リストで中間素材の「📦」を選ぶと、既に用意できている素材として必要数から差し引けます。

準備済み個数を指定する

準備済みの個数を指定すると、まだ必要な中間素材と下位素材の数量がすぐに再計算されます。

ショップ・交換情報を確認する

「🛒」を選ぶと、購入価格、販売場所、交換に必要なアイテムなどを確認できます。

刻限採集の情報を確認する

素材リストに表示される「⏰」を選ぶと、採集可能なエオルゼア時間、エリア、座標、採集方法を確認できます。

お気に入りリストを使う

アイテムを登録する

検索結果やレシピツリーの「📌」から、既存のお気に入りリストへの追加または新しいリストの作成ができます。

リストを作成・名称変更・削除する

お気に入り一覧でリストの操作を開くと、新しいリストの作成、名称変更、削除ができます。

リストとアイテムを並び替える

リストは操作を開いてドラッグし、リスト内のアイテムは「並び替え」モードで移動します。

お気に入り全体の素材を計算する

対象リストを選び、「素材リストを表示」を選ぶと、登録アイテムすべての中間素材、末端素材、クリスタル、交換素材が合算されます。

お気に入りの製作条件を指定する

アイテムごとの個数を指定する

「個数指定」を選び、アイテムごとに作りたい個数を指定します。

「どれか1アイテム」で計算する

「どれか1アイテム」を選ぶと、登録アイテムのどれか1つを作るために必要な最大数を比較して計算します。

指輪の必要数を指定する

指輪を含むリストでは、必要数を0、1つ、2つから選べます。

中間素材の購入・準備済みを一括指定する

お気に入り全体で、中間素材の購入・準備済み指定をまとめて切り替えられます。

設定を変えると、素材リストの数量と製作内容へ即座に反映されます。

複数のお気に入りをまとめて計算する

計算するリストを選ぶ

お気に入り一覧で、計算したいリストの操作を開いてチェックします。

「合算」で計算する

「合算」は、選択した全リストを作る場合の必要素材をまとめて計算します。

「どれか1リスト」で計算する

「どれか1リスト」は、選択した候補のどれか1リストを作る場合に必要な最大数を比較して計算します。

セット数・製作内容・指輪の数を確認する

必要に応じてセット数、製作内容、指輪の数を調整し、「素材リストを表示」で計算結果を確認します。

表示内容を共有する

テキストで共有する

「テキストで共有」を選ぶと、表示外の内容も含めた整形済みテキストが生成されます。掲載画像は撮影時にアプリが実際に出力したテキストです。

画像で共有する

「画像で共有」を選ぶと、共有対象の内容が1枚のPNG画像として生成されます。掲載画像は撮影時にアプリが実際に出力した画像です。

共有するパネルを選ぶ

PC・タブレットでは、画面上部の共有ボタンを開き、検索結果、使用先、レシピ・素材から共有するパネルを選びます。

スマートフォンでは、現在表示しているパネルが共有対象になります。共有する内容を表示してから共有ボタンを開きます。

お気に入りを保存・共有する

シェアコードを発行する

「⚙」の「共有・データ」で共有するリストを選ぶと、シェアコードが発行されます。コピーボタンでコードをコピーし、相手へ渡します。

シェアコードから取り込む

受け取ったシェアコードを「シェアコードから取り込む」へ貼り付け、「取り込む」を選ぶと、新しいお気に入りリストとして保存されます。

シェアコード広場を使う

Discordへ投稿されたシェアコードを、アイテム名と画像付きで確認し、そのままお気に入りへ取り込めます。

全リストをファイルへ書き出す

「全リストを書き出す」を選ぶと、登録済みのお気に入り全リストが1つのテキストファイルとして保存されます。

ファイルからリストを選んで読み込む

「ファイルを選択」で書き出したテキストファイルを選びます。ファイルの読み込み後に表示される一覧で、取り込むリストを個別に選択します。

追加と全置換の違い

「既存を残して追加」は現在のお気に入りを残したまま選択リストを追加します。「既存をすべて削除し、選択したリストで置き換える」は、現在のお気に入りを削除して選択リストだけに入れ替えます。

画面表示と操作を設定する

表示サイズを変更する

「⚙」の「表示」タブでは、文字、絵文字、アイテム画像、チェックなどを80%～170%の10段階で変更できます。表示例を確認してから「反映」を選びます。

PC・タブレットでパネル幅を変更する

左パネル右端の境界をドラッグすると、検索・お気に入り部分の幅を変更できます。

スマートフォンで画面をスワイプ移動する

画面を左右へスワイプすると、検索、使用先、レシピ・素材の各パネルへ順番に移動できます。

小窓で使う

PCでは「⧉ 小窓で開く」を選ぶと、独立した小さいウィンドウでアプリを利用できます。ポップアップが禁止されている場合はブラウザーで許可してください。

ホーム画面・デスクトップから使う

XIVcaのアイコンを、スマートフォンやタブレットのホーム画面、PCのデスクトップに置くことができます。追加したアイコンを選ぶと、ブラウザーでページを探すことなくXIVcaを起動できます。

PCのデスクトップに置く

対応ブラウザーでXIVcaを開き、アドレスバーまたはブラウザーのメニューにある「インストール」などの項目を選びます。追加後は、デスクトップやアプリ一覧に表示されたXIVcaのアイコンから起動できます。通常のブラウザー画面とは別のウィンドウで開きます。

Androidのホーム画面に置く

対応ブラウザーでXIVcaを開き、ブラウザーのメニューから「アプリをインストール」または「ホーム画面に追加」などを選びます。追加後は、ホーム画面に表示されたXIVcaのアイコンから起動できます。

iPhone・iPadのホーム画面に置く

iPhone・iPadでは、Safariから操作する必要があります。SafariでXIVcaを開き、共有ボタンを選びます。表示されたメニューから「ホーム画面に追加」を選び、確認画面で追加します。追加後は、ホーム画面に表示されたXIVcaのアイコンから起動できます。Safari以外のブラウザーでは、この操作はできません。

操作項目の名称や表示位置は、OSやブラウザーのバージョンによって異なる場合があります。

データの保存とアプリの更新

ブラウザーに保存される内容

お気に入り、製作条件、表示サイズ、パネル幅などは利用中のブラウザーへ保存されます。別ブラウザーや別端末へは自動同期されません。

アプリ更新時の動作

起動時に更新を確認し、更新がある場合は利用開始前に適用します。更新後は変更内容が表示され、「OK」を選ぶと利用を開始できます。

データを移行・初期化する場合の注意

端末移行やブラウザー初期化の前に、お気に入りの全リストをファイルへ書き出してください。サイトデータを削除すると、お気に入りリスト等が全て削除されます。
